# 翔自製教學網頁 ｜ 特教適性數位教材大廳

> 督導會議精選展示教材

本專案收錄專為**學習障礙 (Specific Learning Disabilities)**、注意力缺陷 (ADHD) 及認知差異學童量身打造的 **7 套自製特教適性互動教學網頁**。全面實踐**通用學習設計 (Universal Design for Learning, UDL)**，透過視覺表徵化、工作記憶減負與階梯式步驟拆解，賦能學童學習自信。

## 📂 7 大自製適性教學教材導覽

### 1. 📖 語文閱讀與創意寫作
- **[《Alike 大同小異》閱讀思維九宮格](Alike%20閱讀思維九宮格.html)**
  - **特色**：以西班牙無字動畫短片《Alike》為文本，去除文字解碼障礙，獨創「觀察 ➔ 推論 ➔ 找證據」三步驟思維九宮格，支援語音朗讀與個別化教育計畫 (IEP) 評量報告輸出。
- **[《Alike》故事心情與創意寫作九宮格](Alike故事心情與創意寫作.html)**
  - **特色**：針對書寫表達障礙 (Dysgraphia) 與詞彙量匱乏學童，結合動畫角色色彩變化，提供 9 格情境任務卡與即時情緒詞彙庫鷹架，自主連線降低寫作挫折感。

### 2. 🎯 專注力與認知訓練
- **[動態舒爾特方格產生器 (Dynamic Schulte Table)](動態舒爾特方格.html)**
  - **特色**：專為視覺搜尋緩慢、閱讀容易跳字漏行學童設計。支援 3×3 至 7×7 難度，獨家「動態隨機換位模式」鍛鍊眼球動態追蹤與周邊視野，具備語音讀音與本地成績排行。

### 3. 📐 數學運算與表徵輔具
- **[多位數乘法 一步一步算](多位數乘法%20一步一步練習.html)**
  - **特色**：落實「工作記憶減負理論」，將繁複的多位數直式乘法拆解為單步提問與驗證，動態高亮計算位置與進位暫存，提供智慧提示與隨機出題。
- **[數學直式定位板出題產生器](直式定位版題目產生器.html)**
  - **特色**：解決空間知覺困難學童「直式對不齊、進退位混淆」問題。支援加減乘除多位數運算，提供大方格定位板、色彩輔助線，並能一鍵產生教師解答卷與可列印之 Word / PDF 作業單。
- **[線段圖：誰比誰多、誰比誰少](線段圖：誰比誰多、誰比誰少.html)**
  - **特色**：破除學童「看到多就加、看到少就減」的盲目套公式盲點，動態繪製 SVG 比較量與基準量線段圖，分 4 步引導題意分析，並支援作業單與解答 PDF 下載。
- **[長度單位換算：單位階梯與位值滑動尺](長度單位換算：單位階梯與位值滑動尺.html)**
  - **特色**：針對 km、m、cm、mm 換算進退位混淆，整合「具象單位階梯」與「位值滑動尺」雙重視覺表徵，動態呈現小數點彈跳路徑，內建自動出題作業單。

## 💡 督導會議理念與學伴伴讀策略

1. **視覺表徵化 (Visual Representation)**：將抽象數學符號與語文情意轉譯為具象幾何與色彩圖解。
2. **工作記憶減負 (Cognitive Load Reduction)**：拆解繁複解題步驟，讓孩子每次只聚焦一個思考任務。
3. **階梯式成功體驗 (Scaffolded Mastery)**：自主選題、即時提示反饋，維護學童的學習自尊與成就感。

## 🛠️ 技術架構
- **純前端實作**：HTML5 + CSS3 + Vanilla JavaScript，無需任何後端或資料庫。
- **視覺框架**：Tailwind CSS、FontAwesome 6、Google Noto Sans TC。
- **列印保護**：內建 `@media print` 樣式優化，作業單輸出乾淨俐落。
